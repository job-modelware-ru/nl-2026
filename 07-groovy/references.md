\# Список литературы и материалов



Материалы использованы при подготовке презентации \*\*«Apache Groovy: основы языка»\*\*.



\## Apache Groovy



1\. \*\*Apache Groovy Documentation.\*\* Официальная документация языка: синтаксис, типы данных, операторы, методы, замыкания, Groovy Truth и коллекции.  

&#x20;  <https://docs.groovy-lang.org/docs/latest/html/documentation/>



2\. \*\*Apache Groovy — Language Specification.\*\* Спецификация языка Groovy.  

&#x20;  <https://groovy-lang.org/syntax.html>



3\. \*\*Apache Groovy — Semantics.\*\* Материал о динамической и статической типизации, приведении типов и семантике языка.  

&#x20;  <https://groovy-lang.org/semantics.html>



4\. \*\*Apache Groovy — Closures.\*\* Официальное руководство по замыканиям: параметры, вызов и доступ к переменным окружающей области.  

&#x20;  <https://groovy-lang.org/closures.html>



5\. \*\*Apache Groovy — Collections.\*\* Работа со списками, отображениями и методами обработки коллекций, включая `findAll` и `collect`.  

&#x20;  <https://docs.groovy-lang.org/docs/latest/html/documentation/working-with-collections.html>



6\. \*\*Apache Groovy — Operators.\*\* Операторы Groovy, включая арифметические операции, безопасную навигацию и оператор Элвиса.  

&#x20;  <https://groovy-lang.org/operators.html>



7\. \*\*Apache Groovy — Releases.\*\* Сведения о версиях и выпусках языка.  

&#x20;  <https://groovy-lang.org/releases.html>



8\. \*\*The Apache Software Foundation — Groovy.\*\* Официальная страница проекта Apache Groovy.  

&#x20;  <https://groovy.apache.org/>



9\. \*\*Apache Incubator — Groovy Project.\*\* История перехода Groovy в Apache Software Foundation.  

&#x20;  <https://incubator.apache.org/projects/groovy.html>



\## Запуск и программное окружение



10\. \*\*Docker Hub — Groovy Official Image.\*\* Официальный образ Groovy и примеры запуска программ в контейнере.  

&#x20;   <https://hub.docker.com/\_/groovy>



11\. \*\*Oracle — Java Language Updates, Java SE 25.\*\* Описание возможностей языка Java в JDK 25, включая компактные исходные файлы.  

&#x20;   <https://docs.oracle.com/en/java/javase/25/language/>



12\. \*\*Oracle — Java SE 25 Documentation.\*\* Официальная документация платформы Java SE 25.  

&#x20;   <https://docs.oracle.com/en/java/javase/25/>



\## Использованные версии



\- Apache Groovy — \*\*5.1.2\*\*.

\- Java Development Kit — \*\*JDK 25\*\*.

\- Примеры программ запускались локально командой `groovy`.
