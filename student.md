# Курс "Новые языки программирования"

- Результат: теоретическое и практическое знание основ нескольких языков программирования и их стандартных библиотек

- Группы делятся на команды не более 3-х человек

- Команды готовят и выступают с презентациями по выбранным языкам программирования

- Все презентации сохраняются в едином [git-репозитории](https://github.com/job-modelware-ru/nl-2026).

- Все индивидуальные работы хранятся в частных репозиториях, где кроме кода находятся также видео-презентации. Примеры [тут](./video-examples/)

## Командная работа

Команда выбирает язык программирования и создает 3 презентации по данному языку.
Оценка командной деятельности - коллективная.

Первая презентация дожна обязательно включать описание способа запуски программы (docker, онлайн-среда, локальное окружение).

Все презентации сохраняются в git-репозитории. Например, для языка **Swift** команды **01** структура директорий следующая:
- 01-swift\
    - 01\ - первая презентация
        - src\ - исходный код, который используется в презентации
        - 01.pdf - pdf-версия презентации
    - 02\ - вторая презентация
        - src\ - исходный код, который используется в презентации
        - 02.pdf - pdf-версия презентации
    - 03\ - третья презентация
        - src\ - исходный код, который используется в презентации
        - 03.pdf - pdf-версия презентации
    - references.md - список литературы, статей и других материалов

По презентациям могут быть заданы вопросы, на которые нужно дать ответ. Вопросы можно задавать, как на занятиях, так и после них.

## Индивидуальная работа

Индивидуальная деятельность связана с написание 20 программ. 4 программы для каждой темы. Все 20 программ должны быть написаны на 20 разных языках программирования.


Темы:
- многопоточность
- алгоритмическая задача (не менее 2-х с рекурсией)
- ввод/вывод в консоль/файл
- клиент-серверное взаимодействие
- конвертация данных из одного формата в другой


Следует избегать использования специализированных библиотек.

## Темы, которые следует раскрыть в презентациях

- **Общие сведения о языке**
    - История
    - Отличительные особенности
    - Спецификация (версия)

- **Данные и переменные**
    - Типы данных
    - Операции над типами
    - Преобразование/приведение типов
    - Области видимости
    - Владение и передача владения

- **Функции**
    - Входные данные
    - Выходные данные
    - Рекурсия
    - Замыкания

- **Конструкции потока управления**
    - Условные конструкции
    - Циклы
        - Итераторы
    - Блоки

- **Обработка ошибок**
    - Исключения
    - Встроенные средства отладки (assert)

- **Управление сложностью кода**
    - пространства имен
    - модули
    - пакеты
    - импорт
    - экспорт

- **Обобщенные типы**
    - декларация
    - инстанцирование
    - использование

- **Коллекции**
    - массивы, множества, карты, ...

- **Стандартная библиотека ввода-вывода**
    - работа с файлами и консолью

- **Конкурентность / параллелизм**

- **Объектно-, функционально-, протокол-, ...-ориентированное программирование**
    - конструкции
    - способы использования

- **Специфические конструкции языка**

- **Виртуальная машина**
    - общие сведения

- **Управление памятью**
    - общие сведения

## Правила выставления оценок

За курс можно получить максимум 100 баллов, которые соответствуют оценкам:
- 91-100 - отлично
- 71-90 - хорошо
- 51-70 - удовлетворительно
- менее 51 - неудовлетворительно

Баллы начисляются:
- презентации: от 0 до 30
    - на все вопросы, заданные на презентации должен быть дан ответ (сразу, на следующей презентации, в чате)
- вопросы на лекциях: от 0 до 20 (один вопрос от 0 до 2 баллов за **одну презентацию на занятии**)
    - в ТГ после занятия все те, кто задавал вопросы пишут их в формате:
        - ФИО, <название языка программирования>
        - <формулировка вопроса>
        - ФИО, <название языка программирования>
        - <формулировка вопроса>
        - ...
    - Баллы за вопросы начисляются по следующей шкале:
        - 0 - вопрос на уточнение уже сказанного, т.е. реально вопросом не является.
        - 1 - вопрос по теме презентации, на который прямого ответа в презентации нет, но ответ может быть логически выведен из имеющихся данных
        - 2 - вопрос, который актуален для данной темы, но не освещен в презентации
    - В рамках одной презентации одного занятия может быть задано несколько вопросов, но оценивается только один из них
- индивидуальные задания: от 0 до 50
    - по 2.5 балла за каждое сделанное задание
