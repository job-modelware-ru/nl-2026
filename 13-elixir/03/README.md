# Третья презентация: Elixir

- `03.pdf` — презентация, 16 слайдов, версия с заменённым слайдом 06.
- `src/` — исполняемые учебные примеры на Elixir.
- `src/main.exs` — запуск всех локальных демонстраций.

cd 03/src
elixir main.exs
