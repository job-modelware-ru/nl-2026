# ML, часть 3: парадигмы и среда выполнения

В комплект входят:

- `03.pdf` — презентация на 20 слайдов.
- `03.pptx` — редактируемая версия с заметками и источниками.
- `speaker_notes.md` — текст выступления по слайдам.
- `src/` — отдельные примеры OCaml 5.4 и дополнительные примеры F# 9.
- `content.json` — содержание слайдов и ссылки на официальные источники.

Темы идут в порядке: конкурентность и параллелизм, парадигмы, специфические конструкции, среды выполнения, память и ресурсы. База сравнения — OCaml 5.4, Standard ML ’97 и F# 9.

Команды запуска, ожидаемые результаты и пояснения приведены в [src/README.md](src/README.md). Все 12 программ OCaml скомпилированы и запущены через `ocamlc` и `ocamlopt` 5.4.0. Два дополнительных примера F# проверены по документации; для их запуска нужна .NET SDK.
